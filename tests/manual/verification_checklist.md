# Manual UI Verification Checklist

## Visual Fidelity

- [ ] Header and Logo are consistent across all pages.
- [ ] Promocode cards are correctly aligned and styled.
- [ ] Typography matches the brand design (Inter font).
- [ ] Dark mode toggle works and styles update correctly.
- [ ] Color palette is consistent (Grandiose styling).

## Responsive Design

- [ ] Layout is responsive on mobile (iPhone 14 screen size).
- [ ] Navigation menu collapses into a drawer or hamburger on mobile.
- [ ] Images and icons are not pixelated or distorted.

## Interactions

- [ ] Click on "Copy" results in a toast notification.
- [ ] Click on "Activate Link" redirects to the store page in a new tab.
- [ ] Search input provides real-time filtering or clear results.
- [ ] Language switcher updates the URL and content immediately.

## Accessibility

- [ ] All interactive elements have descriptive aria-labels.
- [ ] Color contrast is sufficient for readability.
- [ ] Site can be navigated using only the keyboard (Tab through links).
